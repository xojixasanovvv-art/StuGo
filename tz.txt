1. LOYIHA HAQIDA UMUMIY MA'LUMOT
--------------------------------------------------------
Loyiha maqsadi — mobil ilova va veb-platforma yaratish. U
studentlar va abituriyentlarga boshqa shaharga o'qishga
kelganda turar joy (kvartira), roommate (xonadosh), ish, bilim
almashish, buyum oldi-sotdisi va arzon ovqatlanish bo'yicha
yordam beradi. Barchasi bitta ishonchli, verifikatsiyalangan
muhitda bo'ladi.

Hal qilinadigan muammo:
- Maklerlar kvartira topganlik uchun katta haq oladi (ijara
  narxining 50% va undan ko'p).
- Roommate topish uzoq davom etadi, ishonchsiz va xavfli: kim
  bilan yashash oldindan noma'lum.
- Ota-onalar farzandi kim bilan yashayotganini bilmaydi.
- Studentlar uchun ish, skill, ishlatilgan buyum va chegirmalar
  tarqoq joylarda (Telegram, Instagram) bo'ladi.

Loyiha maqsadi — studentlar makler xizmatisiz to'g'ridan-to'g'ri
kvartira va roommate topa oladigan, keyinchalik esa kundalik
hayot uchun kerakli barcha xizmatlarni o'z ichiga oladigan
ekotizim yaratish.

2. TEXNOLOGIYALAR STACK
--------------------------------------------------------
- Backend framework   : Python, Django + Django REST Framework
- Real vaqt chat      : Django Channels (WebSocket) + Redis
- ORM / Ma'lumotlar bazasi : PostgreSQL (+ PostGIS geo-qidiruv)
- Autentifikatsiya    : JWT (Access + Refresh, SimpleJWT)
- Fon vazifalari       : Celery + Redis (SMS, push, rasm)
- Validatsiya         : DRF serializers / Pydantic
- Server              : Uvicorn / Gunicorn + Nginx
- Hujjatlashtirish     : Swagger / OpenAPI (drf-spectacular)
- Versiya nazorati    : Git + GitHub (CI/CD — GitHub Actions)
- SMS                 : Mahalliy provayder (Eskiz.uz, PlayMobile)
- Push                : Firebase Cloud Messaging
- Fayl saqlash        : S3-mos storage
- Deploy              : Docker, Nginx
- Mobil ilova         : Flutter yoki React Native
- Veb                 : React / Next.js

5. FUNKSIONAL TALABLAR (MODULLAR BO'YICHA)
--------------------------------------------------------

5.1. Autentifikatsiya (Auth)
  - Telefon raqam + SMS (OTP) orqali ro'yxatdan o'tish
    (asosiy usul, O'zbekiston uchun).
  - Qo'shimcha: Google orqali kirish, email.
  - Parolni tiklash, sessiyalarni boshqarish
    (JWT: access + refresh).
  - Bir telefon raqam = bir akkaunt.
  - POST /auth/send-otp, POST /auth/verify-otp,
    POST /auth/refresh

5.2. Profil va Verifikatsiya
  - Profil maydonlari: ism, familiya, rasm, yosh, jins, shahar,
    universitet, fakultet, kurs, qisqa bio, tillar, qiziqishlar.
  - Verifikatsiya usullari (kamida bittasi):
      * Universitet email (@university.uz) tasdiqlash (avtomatik)
      * Student ID karta / talabalik guvohnomasi rasmi + selfi
        (moderator qo'lda tekshiradi)
      * Abituriyentlar uchun: abituriyent ID yoki ro'yxatdan
        o'tganlik hujjati
  - Statuslar: Verifikatsiya qilinmagan → Kutilmoqda →
    Tasdiqlangan / Rad etilgan.
  - Tasdiqlangan foydalanuvchi profilida "Verified student"
    belgisi ko'rinadi.
  - GET/PATCH /profile/me, POST /verification/requests

5.3. Housing (Kvartira e'lonlari)
  - E'lon maydonlari: sarlavha, tavsif, turi (butun kvartira /
    xona / joy), narx (USD/UZS), depozit, shahar, tuman, manzil
    (xaritada nuqta), xonalar soni, maydoni, qavati, jihozlar
    (wifi, kir yuvish mashinasi va h.k.), rasmlar (kamida 3,
    ko'pi bilan 15), hozir yashovchilar soni va jinsi, shartlar
    (chekish, uy hayvonlari), bo'sh bo'lish sanasi.
  - Funksiyalar:
      * E'lon yaratish, tahrirlash, arxivlash, o'chirish
      * Qidiruv va filtrlar: shahar, tuman, narx oralig'i,
        xonalar soni, universitetga masofa, jihozlar
      * Xarita ko'rinishi (Google Maps yoki OpenStreetMap)
      * Sevimlilarga qo'shish
      * Egasiga bevosita xabar yozish (makler yo'q)
      * E'lon egasi statusi ko'rsatiladi (student yoki kvartira
        egasi)
      * Shikoyat qilish (fake e'lon, makler, firibgarlik)
      * Makler nazorati: bir foydalanuvchi bir vaqtda ko'p e'lon
        joylasa (masalan 3 dan ortiq), avtomatik moderatsiyaga
        yuboriladi
  - GET/POST /listings, GET/PATCH/DELETE /listings/{id},
    POST /listings/{id}/favorite

5.4. Roommate (Sherik qidirish)
  - Roommate anketa: byudjet, shahar/tuman, kirish sanasi, jins
    afzalligi, uyqu tartibi, tozalik darajasi, chekish, mehmon
    chaqirish, uy hayvoni, o'qish/ish jadvali.
  - Ikki yo'nalish: "Menda kvartira bor, sherik kerak" va
    "Kvartira ham, sherik ham qidiryapman".
  - Moslik foizi (matching score): anketa javoblari asosida
    hisoblanadi (MVP da oddiy vaznli algoritm).
  - Tavsiyalar ro'yxati (moslik bo'yicha saralangan).
  - Faqat verified foydalanuvchilar bir-birini roommate
    sifatida ko'ra oladi.
  - GET/PUT /roommates/profile, GET /roommates/matches

5.5. Chat
  - 1-ga-1 xabar almashish (matn, rasm).
  - Real vaqt rejimida (WebSocket).
  - Chatdan bloklash va shikoyat qilish.
  - Telefon raqam va shaxsiy ma'lumotlar foydalanuvchi
    roziligisiz ko'rsatilmaydi.
  - Push-bildirishnomalar.
  - GET /conversations, GET/POST /conversations/{id}/messages,
    WebSocket /ws/chat/

5.6. Bildirishnomalar
  - Yangi xabar, verifikatsiya natijasi, e'longa qiziqish,
    yangi mos roommate.
  - Kanallar: push, email (ixtiyoriy), ilova ichida.

5.7. Reports (Shikoyatlar va moderatsiya)
  - POST /reports, POST /users/{id}/block

5.8. Admin panel
  - Foydalanuvchilar ro'yxati va boshqaruvi (bloklash,
    verifikatsiya).
  - Verifikatsiya so'rovlari navbati (tasdiqlash / rad etish +
    sabab).
  - E'lonlar moderatsiyasi.
  - Shikoyatlar ko'rib chiqish.
  - Statistika: ro'yxatdan o'tish, faol foydalanuvchilar,
    e'lonlar, konversiya.
  - /admin/ (Django Admin + maxsus moderatsiya sahifalari)

12. XAVFSIZLIK VA HUQUQIY TALABLAR
--------------------------------------------------------
- Parollar va tokenlar xavfsiz saqlanadi; barcha trafik HTTPS
  orqali.
- Verifikatsiya hujjatlari (ID, selfi) shifrlangan holda, yopiq
  storage'da saqlanadi; faqat moderator/admin ko'radi;
  tasdiqlangandan keyin ma'lum muddatdan so'ng o'chiriladi.
- Rate limiting (OTP, login, xabar yuborish) — spam va
  brute-force'ga qarshi.
- Foydalanuvchi telefon raqami boshqalarga avtomatik
  ko'rsatilmaydi.
- Kiritilgan ma'lumotlarni validatsiya qilish (XSS, SQL
  injection himoyasi).
- Shaxsiy ma'lumotlar to'g'risidagi O'zbekiston qonunchiligiga
  rioya qilish, Foydalanish shartlari va Maxfiylik siyosati
  yozish. (Bu qismni albatta yurist bilan tekshiring.)
- Voyaga yetmaganlar (abituriyentlar 18 yoshdan kichik bo'lishi
  mumkin) uchun alohida cheklovlar: ota-ona roziligi, yoshi
  kattalar bilan yashash e'lonlariga cheklov.
- Firibgarlikdan ogohlantirish: "Oldindan pul o'tkazmang" degan
  ko'rsatma e'lon sahifasida.
